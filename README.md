# Mi pasión por el fútbol

## Descripción
Este proyecto presenta información sobre el fútbol, sus características y su importancia como deporte. También permite practicar la creación de repositorios y el control de cambios con GitHub.
## Objetivo
Conocer la importancia del fútbol, promover el trabajo en equipo y aprender a organizar archivos mediante GitHub.
## Temas del proyecto
- ¿Qué es el fútbol?
- Reglas básicas del juego.
- Importancia del trabajo en equipo.
- Beneficios de practicar deporte.
