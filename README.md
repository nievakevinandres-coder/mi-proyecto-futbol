# Mi pasión por el fútbol

## Descripción
Este proyecto presenta información sobre el fútbol, sus características y su importancia como deporte. También permite practicar la creación de repositorios y el control de cambios con GitHub.
## Objetivo
Conocer la importancia del fútbol, promover el trabajo en equipo y aprender a organizar archivos mediante GitHub.
## Temas del proyecto
- ¿Qué es el fútbol?
- Reglas básicas del juego.
- Importancia del trabajo en equipo.
- Beneficios de practicar deporte.

## Reglas básicas del fútbol

- Cada equipo puede tener hasta 11 jugadores en el campo.
- Un partido normal dura 90 minutos, divididos en dos tiempos de 45 minutos, sin contar el tiempo añadido.
- Los jugadores deben respetar las decisiones del árbitro.
- El objetivo es marcar más goles que el equipo contrario.
- No se permite tocar deliberadamente el balón con la mano o el brazo, salvo las excepciones previstas en las reglas.
